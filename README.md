# THAUMWORLD-LORE

Canonical lore repo for thaumworld.

## What this repo is
- scale-first worldbuilding archive
- markdown pages hosted through GitHub Pages
- readable by humans, agents, and future tools

## How it works
- every folder is a page through its `index.md`
- scale determines where content lives
- time determines when content is relevant in context
- facets split detail when a page gets too dense

## Scale ladder
- universe
- galaxy
- solar_system
- celestial_body
- region
- place
