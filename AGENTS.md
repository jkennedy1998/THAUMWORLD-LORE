# AGENTS

This repo stores canonical thaumworld lore.

## Core rules
- everything in canon-facing folders is canonical
- organize content by scale first
- use time context already declared on pages
- use subpages for specificity, not uncertainty
- do not invent lore or write canon prose without user-provided content
- ask questions that help the user develop missing areas
- help organize, route, evaluate implications, and maintain structure

## Working rules
- a thing lives at the smallest scale that meaningfully owns it
- use the canonical facet list from `meta/docs/structure.md`
- use promotion when needed: mention -> list entry -> promoted page
- parent pages summarize and link downward
- child pages hold detail and link upward

## `meta/`
`meta/` is the non-public work zone.
Use it for plans, schema notes, spitballs, sorting, and refinement before canon-facing updates.
