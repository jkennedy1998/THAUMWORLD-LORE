# thaumworld_world
> a system for organizing canonnical texts of thaumworld

## nutshell

this website / file structure system uses index.md files hosted through github pages to accomplish the following
> allow clickable traversal of the universe to humans

> allow a crawlable site for ai agents

> every folder is a “page” via its local index.md

> every page has sub pages so that main pages dont become over populated
