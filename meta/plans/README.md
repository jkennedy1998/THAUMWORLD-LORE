# Plans

Use this folder for active repo planning.

## Rules
- Write plans for both humans and agents.
- Use the template below for all plans.
- Keep plans minimal and phase-based.
- Put a short project-state paragraph at the top of every plan.
- Update checklist states directly while working.
- Archive old or finished plans in `meta/plans/archive/` when they are no longer active.
- If another piece must be worked on first in another plan, cross-reference the dependency.

## Status key
- `[ ]` not done
- `[+]` implemented
- `[#]` tested
