# Structure

## Scale ladder
- universe
- galaxy
- solar_system
- celestial_body
- region
- place

All scales may have child folders.
Every folder is a page through its `index.md`.

## Canonical facets
- geography
- culture
- life
- technology
- thaumatry
- characters
- places
- science

Use only the facets that improve readability.
Not every page needs every facet.

## Facet meanings
- `geography` : physical layout and environment
- `culture` : intelligent social life, groups, government, trade, custom
- `life` : species, ecosystems, and lifeforms broadly
- `technology` : applied tools, infrastructure, engineering, practical magical technology
- `thaumatry` : local magical practice, religion, glyph use
- `characters` : meaningfully written intelligent individuals
- `places` : named sub-locations inside the parent scale
- `science` : discovered truth about how the world works

## Ownership rule
A thing lives at the smallest scale that meaningfully owns it.

## Promotion rule
A thing grows like this:
- mention
- list entry
- promoted page

Use mentions for brief references.
Use list entries in facet files like `places.md` or `characters.md` when something should be easy to find.
Use promoted pages when detail or future growth justifies a child folder.

## Parent and child rule
- parent pages summarize, relate, and link downward
- child pages hold detail and link upward

## Linking rule
Prefer clean, consistent links.
A parent page should make its child pages easy to reach.
A promoted child should stay reachable from its parent page or facet.

## Scale use
- large scales hold broad truths and overview
- middle scales hold major world structure and subdivision
- region is the main local worldbuilding scale
- place is the smallest formal scale and is useful for play-facing detail
